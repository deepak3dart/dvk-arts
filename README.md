# DVKarts

Portfolio site for Deepak Vishwakarma (DVKarts) — artist working in pencil, ink, watercolor, and digital illustration for children's books. Live at [dvkarts.com](https://dvkarts.com).

## Structure

Static HTML/CSS site, no build step or dependencies.

- `index.html` — home page
- `works.html` — portfolio grid, filterable by medium
- `app.html` — landing page for the SketchLog Android app
- `contact.html` — contact links
- `privacy.html` — privacy policy for SketchLog
- `style.css` — shared stylesheet
- `images/` — site and artwork images
- `CNAME` — custom domain for GitHub Pages

## Deployment
Served via GitHub Pages. Pushing to `main` publishes directly — no build step required.
